This project is Task 2 of the SRM NSCC Technical Recruitment Tasks.

It is a responsive personal introduction page designed to present information about me, including my introduction, interests, hobbies and skills.

The page focuses on creating a clean, attractive and interactive user experience using HTML, CSS and JavaScript.

## Dark/Light Mode

The page includes a Dark/Light Mode toggle as an additional feature.

When the theme button is clicked, JavaScript switches the page between dark and light themes.

The selected theme is also stored using localStorage.

This means that when the page is refreshed, the previously selected theme is automatically restored.

## Responsive Design

The website is designed to work across different screen sizes.

A CSS media query is used to adjust the layout for smaller screens such as mobile phones.

The layout changes so that content remains readable and accessible without requiring horizontal scrolling.

## Challenges and Solutions

### Responsive Design

A major consideration was making sure the page remained usable on both desktop and mobile screens.

This was handled using responsive CSS and media queries that adjust the layout at smaller screen sizes.

### Dark/Light Mode

The page needed to allow the user to switch between themes while also remembering their choice.

JavaScript was used to toggle the `light` class on the body, while localStorage was used to save the selected theme.

### Connecting the Two Tasks

Since both tasks are contained within the same GitHub repository, relative paths were used to connect the Personal Introduction Page with the Signup Dashboard.
